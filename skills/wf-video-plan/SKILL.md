# Plan and create a YouTube video

Set KIND to `videos`, project_type to `video`, orientation to landscape 16:9. Read `../wf-reel-plan/references/planning.md` and follow it for the supplied topic, folder or project. Resolve the studio two directories above this skill. Use the shared production reference for rendering, rather than the single-video quick-edit workflow.

Never ask about visual effects in chat. Visual choices must be selected by the creator in the interactive HTML plan review (`/review/videos/<slug>`), where suggested effects display dummy sample cards and reasons.
