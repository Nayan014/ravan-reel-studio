# Official map sources

Verified on 2026-11-17. Recheck when sourcing a new edition or preparing a deliverable with different usage rights.

- [Survey of India outline maps](https://surveyofindia.gov.in/pages/outline-maps-of-india): official outline products and an international-boundary vector ZIP. Follow the page's current links rather than assuming a cached filename is the latest edition.
- [Official outline vector ZIP](https://surveyofindia.gov.in/documents/Outline_of_India.zip): the inspected archive contains polygon geometry and a `.prj` file describing Lambert Conformal Conic/WGS84. Keep all rings, including islands. Read the actual archive metadata; do not treat projected metre coordinates as longitude/latitude.
- [Survey of India political maps](https://surveyofindia.gov.in/pages/political-map-of-india): reference for states, union territories and the official national depiction. Use the appropriate current edition for labels and divisions.
- [Outline vector usage notice](https://surveyofindia.gov.in/files/IBD%20Vectorformat.pdf): this notice describes individual/internal/educational/research/website uses and prohibits commercial use of that outline product. Retain this notice alongside the downloaded source; do not infer public-domain status from “free”.
- [Survey of India copyright policy](https://surveyofindia.gov.in/pages/copyright-policy): describes reproduction permissions and the required acknowledgement. Use the exact acknowledgement, **Source: Survey of India, Government of India.**, when applicable. Check the product-specific terms as well as this policy; escalate only an actual unresolved reuse requirement, not ordinary local inspection.

These references establish the studio's chosen boundary standard. They are not a licence to redistribute official source data in the skill package or a claim that a derived graphic has been certified. Save the actual product terms and whether the intended use is covered in the project manifest.
