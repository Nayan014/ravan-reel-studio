# Ravan Reel Studio

Read `AGENTS.md` in this folder for the shared skill index and workflow. For `Start video edit` or `/video-edit`, follow `skills/video-edit/SKILL.md`; it guides selection and waits for approval of actual frames before rendering. For a direct effect request, use `skills/effects/SKILL.md`. The `.agents/skills/` entries point to the canonical local packages.

Use `skills/wf/SKILL.md` for `/wf`, including `/wf video-edit`. Bare `/wf` shows the local command menu. Project command definitions are under `.gemini/commands/`.

Use `/wf-reel-plan` for a portrait reel or `/wf-video-plan` for a landscape YouTube video, starting from an idea, footage or a saved project. Both continue through review and export. `/wf-video` remains the quick single-video editor.
