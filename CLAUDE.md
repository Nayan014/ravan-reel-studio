# Ravan Reel Studio

Read `AGENTS.md` in this folder for the shared skill index and workflow. For `Start video edit` or `/video-edit`, follow `skills/video-edit/SKILL.md`; it guides selection and waits for approval of actual frames before rendering. For a direct effect request, use `skills/effects/SKILL.md`. Use the local renderer and runtime. This project is usable without a global Claude skill installation.

Use `skills/wf/SKILL.md` for `/wf`, including `/wf video-edit`. Bare `/wf` shows the local command menu.
